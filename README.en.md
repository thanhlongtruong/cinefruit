# 🎬 Movie Ticket App - CineFruit

Fast and simple movie ticket booking application, intergrated online payment and viewing showtime by theater.

## 🔑 Main features

- Login, register, forgot password.
- Showtimes by movie and by theater.
- Choose and hola seat for a certain amount of time.
- Payment Paypal and Momo.

## 🛠️ Technology used

- Flutter
- Node.js + Express
- MongoDB
- JWT Authentication
- Postman
